    💡 Önskelista

      Sorterad på röster, sedan datum. Status syns för användarna ("Dold" gömmer önskan för alla utom den som skrev den). I SQL: select * from owner_wishes_v;

      💾 Databas · gratisplan 500 MB DB, 5 GB egress / mån

      📅 Event

      Användarnas tips syns bara för den som skrev dem tills du godkänner. Importerade event (Ticketmaster, iCal, JSON-LD) är godkända direkt; dölj dem här vid behov.

      ➕ Nya ställen

      Förslag från kartans långtryck (”Lägg till ställe här”). Godkänn = stället läggs i bars_lite (aktivt, id u-…) så pins och incheckningar fastnar där. Avvisa = dolt (ingen rad tas bort).

      🚩 Barrapporter

      Bara summor. Inga namn, inga exakta platser, inga användar-id. Skål, reaktioner och chatt försvinner när en natt tar slut, så 7 d-siffrorna kan vara för låga. Uppdateras var 60:e sekund när sidan syns.
